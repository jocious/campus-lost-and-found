# Campus Lost & Found

A beginner-friendly web application for university students to report and search for lost and found items.

## Features

- Add lost items
- Add found items
- Search for items
- Filter items by status
- Delete reports
- Save reports using localStorage
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Open the website.
2. Fill out the Report an Item form.
3. Click Add Report.
4. The item will appear under Reported Items.
5. Use the search box to find an item.
6. Use the filter to show Lost or Found items.
7. Click Delete to remove a report.
